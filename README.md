# Block Blast Solver (APK)

1. Crie um repositório no GitHub e envie **todos** os arquivos desta pasta (inclusive a pasta `.github`).
2. Abra a aba **Actions**. O workflow "Build APK" roda sozinho a cada envio (ou clique em "Run workflow").
3. Quando terminar, abra a execução e baixe **BlockBlastSolver-apk** em "Artifacts". Dentro do .zip está o `app-debug.apk`.
4. Instale no celular (permita "instalar apps de fontes desconhecidas").

Uso no celular: tire um print do jogo, abra o app, toque em "Enviar print", marque o tabuleiro e as peças (só na primeira vez).
